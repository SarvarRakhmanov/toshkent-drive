# Legacy Toshkent Drive (Grok Build version)

The original single-district game made in Grok Build (Vite + React + three.js),
kept here for reference: Amir Temur Square map, missions, garage, so'm economy.
Its 3D models are not duplicated here; the cars and buildings the new engine
uses live in `../public/models/`. See `MODEL_CREDITS.md` / `SKETCHFAB_CREDITS.txt`.
